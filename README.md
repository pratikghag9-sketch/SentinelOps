# SentinelOps — Automated Server Backup & Monitoring System

A production-grade DevOps automation tool that handles server backups and system health monitoring using Linux Shell Scripting and AWS.

## Features
- Automated compressed backups with timestamps
- Auto-cleanup of old backups (retains last 3)
- Detailed logging of all operations
- System health monitoring (coming soon)
- AWS S3 cloud backup integration (coming soon)

## Tech Stack
- Linux (Ubuntu/WSL)
- Bash Shell Scripting
- AWS S3

## Project Structure
SentinelOps/
├── backups/      # Backup files stored here
├── config/       # Configuration files
├── logs/         # Operation logs
└── scripts/      # Shell scripts

## Usage
```bash
bash scripts/backup.sh
```
